# Screenshots

Place the plugin's screenshots in this folder. The `README.md` at the repo
root references two images:

| File | What to capture |
|------|-----------------|
| `map-view.png` | The 2D map view of a board note — show the Activity → Task → Epic column headers, the Release rows, a few story cards, and (ideally) an "Unassigned" section and a dimmed broken-link card. |
| `debug-panel.png` | The same map with **Debug mode** enabled, so the metrics overlay (FPS / Stories / Render ms) is visible in the bottom-right corner. |

Capture from a real Obsidian instance (Desktop) at a comfortable window size.
Both light and dark theme captures are welcome if you want to show theme
adaptation. Replace the files here before creating the release — the
Constitution requires real screenshots in the README (no placeholders).
